# 旅誌 Trip Notes

手機優先、多人共編的旅遊行程網站。旅伴不用註冊帳號，**拿到連結就能看、也能編輯**，大家的修改幾秒內就會同步。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/lins4348h/trip-notes-template)

## 可以做什麼

- **行程**：每天一個顏色與封面大字，按住右邊的 ⋮⋮ 拖曳排序，也能搬到別天；時間順序不對會跳出提醒；地點一點就開 Google 地圖；行程之間可以寫交通方式和車程。
- **預約**：待辦清單，訂好就打勾，有完成進度。
- **記帳**：當地貨幣和台幣互相換算、多人分帳、自動算出誰該付給誰、每天花多少。
- **提醒**：營業時間、服裝規定等注意事項，也會出現在當天的行程下方。
- **當地語言**：內建泰語、日語、韓語的救急句，點喇叭聽發音，點句子放大給店家看；可以自己新增句子。
- **旅程設定**：旅程名稱、日期、天數、每天的封面大字、顏色（6 組城市配色）、插畫（16 種），全部在網站上改，不用碰程式。

## 你需要準備

- 一個 **GitHub** 帳號（免費）：[github.com/signup](https://github.com/signup)
- 一個 **Cloudflare** 帳號（免費）：[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)

旅伴什麼帳號都不用。

## 架設步驟（大約 10 分鐘，只做一次）

1. **按上面的「Deploy to Cloudflare」按鈕。**
2. **登入 Cloudflare。** 第一次使用會請你連結 GitHub 帳號，照畫面按「授權」。Cloudflare 會在你的 GitHub 建一份這個網站的副本。
3. **填寫部署設定。** 畫面上大部分欄位用預設值就好，只有兩個要注意：
   - **專案名稱**：會變成網址的一部分，例如填 `kyoto-2027`，網址就會是 `kyoto-2027.你的帳號.workers.dev`。只能用英文小寫、數字和 `-`。
   - **EDIT_KEY**：這就是**分享連結的密碼**。自己想一組 16 字以上的英文＋數字，例如 `Kyoto2027abcXYZ789`。不要用平常的密碼，先記下來。
   - 資料庫（DB）不用設定，Cloudflare 會自動建立。
4. **按「建立並部署」**，等 1～2 分鐘。
5. **拿到網址。** 部署完成後，畫面會顯示網站網址（結尾是 `.workers.dev`）。第一次使用 Cloudflare 的人，可能會先被請你取一個 workers.dev 的子網域名稱，照畫面填就好。
6. **組出分享連結：** 在網址後面加上 `/#k=你的密碼`，例如：
   ```
   https://kyoto-2027.你的帳號.workers.dev/#k=Kyoto2027abcXYZ789
   ```
   把這個完整連結傳給旅伴。

> 如果第 3 步沒有出現 EDIT_KEY 欄位：部署完成後，到 Cloudflare 左側選單「Workers 和 Pages」→ 點你的專案 →「設定」→「變數和祕密」→「新增」，類型選「祕密」，名稱填 `EDIT_KEY`，值填你的密碼，儲存後網站會自動更新。

## 第一次打開網站

1. 打開剛剛組好的分享連結。
2. 會先問「**你是誰**」：範例只有旅伴 A～C，先按「先跳過」。
3. 接著會看到**曼谷五天四夜的範例**。可以先逛逛每個分頁，了解怎麼用。
4. 準備好之後，按「**清空範例，建立我的旅程**」，填上：
   - 旅程名稱、英文小標、出發日期
   - 當地語言（泰語／日語／韓語／英語／不需要）和當地貨幣
   - 旅伴名字（記帳和「你是誰」會用到）
   - 每一天的封面大字（2 個字最好看）、主題、顏色和插畫
5. 按「儲存設定」，就可以開始新增行程了。

之後要改設定，點右上角的**齒輪**。要換「你是誰」，點右上角的「**即時同步**」。

## 日常使用小提醒

- **連結就是編輯權限。** 只傳給旅伴，不要貼在公開的地方。
- **兩個人同時改同一筆，以最後儲存的為準。** 不同筆同時改沒問題。
- **匯率要自己更新。** 記帳分頁最下面的「設定：匯率與成員」可以改。換了當地貨幣後，匯率會先換成一個參考值，出發前請改成當時的匯率。
- **發音用的是手機內建的語音。** 沒聲音的話：
  - iPhone：設定 → 輔助使用 → 朗讀內容 → 聲音，下載該語言；另外確認沒有開靜音模式。
  - Android：設定 → 文字轉語音 → 安裝語音資料。

## 常見問題

**連結外流了怎麼辦？**
到 Cloudflare →「Workers 和 Pages」→ 你的專案 →「設定」→「變數和祕密」，把 `EDIT_KEY` 改成新的密碼，再把新的連結傳給旅伴。舊連結會立刻失效。

**要花錢嗎？**
一般使用不用。免費方案每天大約有 10 萬次資料查詢；網頁只有開在螢幕上時才會同步，放著不動一分鐘後也會降低同步頻率，7 個人每天各用 2 小時大約 1 萬多次。超過的話，當天同步會暫停到隔天早上 8 點（台灣時間），網頁仍然打得開。

**想再辦一趟新的旅行？**
再按一次上面的部署按鈕，取一個新的專案名稱就好，每趟旅行各自獨立。也可以在原本的網站按齒輪，直接改成新的旅程。

**這個模板之後更新了，我的網站會跟著變嗎？**
不會。部署時 Cloudflare 會在你的 GitHub 建一份副本，之後就是你自己的版本，不會被別人改到。

**看得到別人的旅行資料嗎？**
不會。每個人部署的網站和資料庫都是分開的，放在各自的 Cloudflare 帳號裡。

## 給會寫程式的人

| 檔案 | 用途 |
|---|---|
| `public/index.html`、`styles.css`、`app.js` | 網頁本體（原生 JS，無建置步驟） |
| `public/adapter.js` | 前端資料層：輪詢 `/api/sync` 同步、樂觀更新、密鑰與「你是誰」 |
| `src/worker.js` | Cloudflare Worker：`/api/*` 讀寫 D1，其他路徑交給靜態檔 |
| `src/seed.js` | 第一次啟動時寫入的範例資料 |
| `wrangler.json` | Worker、靜態檔與 D1 綁定設定 |

本機開發：

```bash
npm install
cp .dev.vars.example .dev.vars   # 在 .dev.vars 填 EDIT_KEY=任意密碼
npm run dev                      # 打開 http://localhost:8787/#k=你的密碼
```

資料存在 D1 的一張 `docs` 表（`col`、`id`、JSON `data`、`deleted`、`updated_at`），第一次收到請求時會自動建表並寫入範例資料，不需要 migration。

API（都需要 `x-edit-key` 標頭）：

- `GET /api/sync?since=毫秒`：取得變動的文件
- `PUT|PATCH|DELETE /api/doc/:col/:id`：整份寫入、合併欄位、刪除
- `POST /api/batch`：一次多筆寫入，body 為 `{ ops: [{ op, col, id, data }] }`
